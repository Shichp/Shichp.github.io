## 维护正式公示

编辑 `data/publications.js`，更新 `window.KT_PUBLICATIONS`。三个数组为空时分别显示“对阵待公布”“比赛结果待公布”“中奖名单待公布”。不要把示例数据发布成正式比赛结果。

### 字段

| 数组 | 每条记录的字段 |
| --- | --- |
| matches | project 项目、round 轮次、sideA / sideB 对阵双方、scheduledAt 时间、venue 场地、status 状态、scoreA / scoreB 比分、winner 胜者 |
| results | project 项目、rank 名次、name 姓名或组合、team 队伍、score 成绩、points 积分、note 备注 |
| winners | name 姓名、team 队伍、prize 奖品、publishedAt 公布日期、note 备注 |

`updatedAt` 为整份公示的更新时间文字。日期、姓名、队伍等按显示内容填写；项目名称请与 `js/config.js` 一致，例如“羽毛球-男单”。无比分时双方比分留空，已结束的比赛可填写数值（含0分）。双打组合可在 `sideA`、`sideB` 或 `name` 中填写两人姓名。

公示中的姓名与内容通过 `textContent` 作为普通文字显示。结果按信息组提供的顺序展示，不从比分推断官方排名，不自动计算赛事积分。只发布经核对、适合公开的对阵、结果及名单。

当前只提供名单展示，不包含随机抽奖、开奖、登录或后台写入功能。网站不接 CloudBase。
