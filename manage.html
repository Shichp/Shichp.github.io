成绩更新与 Excel 预览

先检查成绩，再由负责人上传 GitHub 发布。选择文件只在当前浏览器中预览，不会修改线上成绩。

1. 准备 Excel

下载当前成绩表 下载填写示例

第一次使用时，当前成绩表为空模板。填写示例中的人名和比分均为演示，请勿直接作为正式成绩发布。

  • 保留「对阵成绩」「团体积分」「个人积分」三个工作表，第一行列名保持不变。不发布的数据表只保留标题行。
  • 未赛：比分A、比分B、胜者都留空。已赛：填写双方比分，胜者填 A 或 B；弃权填「弃权」。
  • 人数、积分填写非负数字，没有则填 0。团体及个人积分由负责人核定后填写，网站仅计算合计与排序。
  • 请使用 .xlsx；若使用公式计算积分，发布前将数据复制并「粘贴为值」。

2. 校验并预览

请选择 Excel 文件。文件仅在本机读取。

请同时核对三张表。每次发布会用整份 Excel 替换上一个版本，空表将清除对应列表，不会自动合并历史记录。

3. 上传 GitHub 发布

  1. 校验通过并核对预览后，下载上方待上传文件，文件名保持 results.xlsx。
  2. 登录 GitHub，进入运动会网站仓库的 data 文件夹。
  3. 点击 Add file → Upload files，上传 results.xlsx，替换同名文件。
  4. 填写本次更新说明，点击 Commit changes 提交到发布分支。如果提交到其他分支，需要合并后才发布。
  5. 在仓库 Actions 中等待 Pages 发布成功，再回到网站点击“刷新成绩”，核对正式结果。

更新可能需要约 10 分钟。这个预览页对所有人可见，但只有拥有仓库写入权限的负责人才能发布。无需在网页输入 GitHub 密码或令牌。
